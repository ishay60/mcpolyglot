  ▲  mcpolyglot   MCP   v0.0.1
     one config, every database your agent needs

Usage: mcpolyglot [options] [command]

Turn your databases and APIs into Model Context Protocol servers.

Options:
  -V, --version         output the version
  -h, --help            display help

Commands:
  init [options] [url]  Interactively scaffold an mcpolyglot.config.ts in the
                        current directory.
  serve [options]       Start the mcpolyglot MCP server.
  doctor [options]      Validate config, resolve secrets, ping each source, and
                        list generated tools.
  tools [options]       List all tools that mcpolyglot would expose for the
                        current config.
  token                 Manage per-agent HTTP bearer tokens.
  help [command]        display help for command

  docs: github.com/ishay60/mcpolyglot
